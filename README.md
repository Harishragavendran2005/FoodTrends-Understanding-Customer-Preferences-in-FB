## 🎯 Overview

**FoodTrends** is a comprehensive data analytics project that leverages Power BI to analyze food consumption patterns, nutritional intake, and lifestyle behaviors. By examining the intersection of dietary preferences, health conditions, and activity levels, this project provides actionable insights for individuals and organizations seeking to make data-driven decisions about nutrition and wellness.

### 🎓 Project Objectives

- 📊 Analyze dietary preferences across different demographics
- 🥗 Evaluate comprehensive nutrition intake (calories, protein, fat, carbohydrates, fiber, sugar)
- 🏥 Understand the relationship between nutrient consumption and chronic diseases
- 🏃 Examine how physical activity and lifestyle impact nutritional choices
- 💡 Provide evidence-based insights for healthier lifestyle decisions

---

## ✨ Key Features

- **📈 Interactive Dashboards**: Four comprehensive Power BI dashboards covering different aspects of nutrition analytics
- **🔍 Multi-dimensional Analysis**: Explore data across demographics, diet types, activity levels, and health conditions
- **📉 Health Correlation**: Identify relationships between nutrients and diseases like diabetes and hypertension
- **🍳 Meal-specific Insights**: Dedicated analysis of breakfast choices and their impact on daily nutrition
- **⚡ Real-time Filtering**: Dynamic filters for personalized insights based on specific criteria
- **📊 Visual Data Storytelling**: Clear, intuitive visualizations that make complex nutrition data accessible

## 📁 Dataset Information

The project utilizes three comprehensive datasets covering various aspects of food consumption, nutrition, and health indicators.

| File Name | Description | Key Attributes |
|-----------|-------------|----------------|
| `Food_and_Nutrition.csv` | Detailed food consumption, nutrition, and lifestyle data | Calories, macronutrients, demographics, health conditions |
| `nutrition_dataset_10000.xlsx` | Large-scale dataset with nutritional values and health indicators | BMI, activity levels, dietary preferences, disease markers |
| `Exact_Breakfast_Dashboard_Data.xlsx` | Specialized dataset for breakfast analysis | Meal types, ratings, prices, nutritional breakdowns |

### 📋 Dataset Attributes
- **Nutritional Metrics**: Calories, protein, fat, carbohydrates, fiber, sugar, sodium
- **Dietary Preferences**: Omnivore, Vegetarian, Vegan, Pescatarian, etc.
- **Health Indicators**: BMI, disease conditions (diabetes, hypertension), activity levels
- **Demographics**: Gender, age groups, lifestyle factors
- **Food Characteristics**: Meal types, ratings, pricing, portion sizes

## 💡 Key Findings

### 🎯 Overall Insights

1. **Activity Matters**: Physical activity level is the strongest predictor of both calorie intake and BMI
2. **Diet Type Impact**: Omnivore diets consistently show higher protein and overall nutrient intake
3. **Breakfast Importance**: High-protein breakfast choices correlate with better daily nutritional balance
4. **Price-Quality Relationship**: Higher-priced food items contribute more to nutritional intake
5. **Gender Differences**: Sodium and sugar consumption patterns vary between genders
6. **Disease-Diet Link**: Specific health conditions significantly influence dietary choices and restrictions
